## 🕉️ About

**Sushmitha Codes Art** is a personal digital art portfolio that blends **Indian heritage** and **modern creativity**.  
The artwork is inspired by **Hindu gods** and the timeless philosophies they represent — reinterpreted through the calm rhythm of **digital illustration** and occasionally enhanced using **p5.js generative art**.

Each piece aims to translate divinity into a modern visual language — where art leads, and code simply illuminates.

---

## 🌿 Features

- 🎨 Minimal, elegant UI inspired by Indian tones and motifs  
- 💻 Hand-coded with **HTML**, **CSS**, and **JavaScript**  
- 🪷 Occasional **p5.js** backgrounds for coded motion and vibrance  
- 🔒 Secure, static, HTTPS-ready website  
- 🖋️ Refined typography using *Playfair Display* and *Lora*
